# React frontend

This is the Vite frontend for Ruby vs Sapphire. It is connected to the FastAPI and Supabase backend in the parent directory. See `../README.md` for setup and deployment.

Run `npm run dev` from the **parent directory** to launch both servers. Running it here starts only Vite, which expects FastAPI at port 8000.

The old `preview.html` and `export-preview.mjs` are legacy standalone mockup artifacts, not the connected application. Use the development servers for real gameplay.
